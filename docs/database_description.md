# Описание базы данных

![Общая информация о структуре базы](/docs//images/compresed_db_info.png)

На данный момент структура базы данных представляет собой 4 таблицы и 2 представления. Основной таблицей является __container_info__, она
содержит основную информацию о контейнерах: id, имя контейнера, статус активности и ограничения по памяти. Оставшиеся таблицы содержат 
статистическую информацию об этих контейнерах, разбитую на логические группы:
- __container_stats__ -- общая статистика об использовании памяти и процессора
- __container_detailed_statistics__ -- более детальная статистика об использовании процессора
- __container_networks__ -- статистика об использовании сети

![Граф зависимостей таблиц](/docs/images/relationships.implied.large.png)

Кроме таблиц есть представления:
- __dashboard_table__ -- основная агригированная информация по всем контейнерам; значения из этого представления используются для отображения инфомарции на заглавной страницы веб-интерфейса
- __container_aggregation__ -- более расширенная агрегированная статистика, которая расчитывается каждый час

![Представление dashboard](/docs/images/dashboard_table.1degree.png)

![Представление aggregation](/docs/images/container_aggregation.1degree.png)

Таблицы со статистиками и представления связаны с основной таблицей __container_info__ через внешние ключи. В основной таблице идегтификатор
контейнера является первичным ключем, во всех остальных таблицах это поле является внешним ключем и отсылается к идентификатору контейнера
в основной таблице.

Стоит сказать, что представление __container_aggregation__ и таблицы __container_stats__, __container_detailed_statistics__, 
__container_networks__ сделаны с помощью расширения timescaledb. В частности это означает, что физически эти таблицы делятся на временные 
партиции, каждая из которых уже имеет связь с основной таблицей.
